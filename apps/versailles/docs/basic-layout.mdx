## What is a Basic Map Layout?

A basic map layout is a layout that you see no matter what map mode you are currently in.

## How to read the Basic Map Layout?

<img src="/public/references/basic-layout.png" alt="basic layout schema"></img>

The layout consists of the following components:

### Biomes

[Biomes](/map/biomes) are shown on each tile and are located on the lowest layer of the map.

### Hex Colors

Each tile can have a specific color which is linked to the nation that controls it.
If a hex has no color, it is considered empty.
