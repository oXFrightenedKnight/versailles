## How to read Economy Map?

<img src="/public/references/economy-map.png" alt="Economy map schema"></img>

Besides the [basic layout](/map/basic-layout), the map consists of the following components:

### Road Graph

Road graph consists of white, dashed lines that represent road paths between tiles.

### Building Icons

Building icons are found on all hexes that have buildings built on them. The icon
depends on building [category](/buildings/categories).

### Level Labels

Next to every building icon, you can find a level label. The number on the label
shows current building level on this tile.
