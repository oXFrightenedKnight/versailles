## Step 1:

Start by clicking on the **"menu"** icon on the right of the navbar.

<img
  src="/public/references/settings-1.png"
  alt="Navigating settings menu from game instance image"
></img>

A dialog will pop up in the middle of the screen.

<img
  src="/public/references/settings-2.png"
  alt="Navigating settings menu from game instance image"
  className="w-64"
></img>

## Settings Options:

1. **Continue.**
   Pressing this button will hide the dialog and the game will continue.

2. **Load Game.**
   Pressing this button will redirect you to **"Saves"** menu.

3. **Home.**
   Pressing this button will redirect you to **"Main"** menu.
