## What is Diplomacy Menu?

Diplomacy Menu is used to allow players to realize diplomacy with other nations.

## How to open Diplomacy Menu?

To open Diplomacy Menu, locate **Diplomacy** button on the right side of the game navbar.

## Navigation

Once you open Diplomacy Menu, select you will see a list of all existing nations to choose
from. Select any nation you would like to manage your relations with.

The menu will be split into two sections:

### Info Section

This section is used to read information about selected nation. The information
includes: ongoing war list, peace treaty list, number of buildings built, number of
occupied hexes, etc.

### Action Section

This section is used to directly interact with select nation. Currently you can only
declare war or send a peace request if you are fighting this nation.
