## What is a Contract Component?

The Contract Component is a menu nested inside [Building Configuration](/buildings/building-menu)
to help players create and manage their contracts.

<img src="/public/references/contract-component.png" alt="Contract component example"></img>

## How to create a new contract?

Follow these steps to create a new contract:

1. Choose a building you want to **export** from and a building to **receive** the exported resource.
2. Make sure you meet all [requirements](/contracts/contracts) for creating a new contract.
3. First, click on the building tile you want to send a resource from. If this building is eligible,
   you will find a Contract Component inside [Building Menu](/buildings/building-menu).
4. Locate a **"Square Pen"** icon at the top of the component. Click on it to activate contract creation mode.
5. Click on the **receiving** building tile.

## Reading a contract

All contracts are located inside the Contract Component and consist of the following features:

1. -/+ buttons. These buttons are used to adjust a contract's exported amount. **Warning:**
   changing the contract amount will disable the **"Auto-Adjust"** feature.
2. Amount label. Shows the current export amount.
3. Auto-Adjust. Used to change the contract type between "Fixed" and "Flexible".
4. Exported Resource. Displays the currently exported resource. Click to switch to another available resource.
