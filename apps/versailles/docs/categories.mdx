## What are building categories?

Building categories define what properties and features a building has. Currently, there
are 5 building categories in Versailles.

### Civilian

This is the most fundamental category. Civilian buildings mainly provide the nation with
**manpower** and **gold**.

<img src="/public/references/civilian.png" alt="Civilian building icon" className="h-32"></img>

### Barrack

The biggest difference of this category is the ability to **train armies**.

<img src="/public/references/barrack.png" alt="Barrack building icon" className="h-32"></img>

### Farm

This category produces one of the most vital resources in the game - **wheat**.

<img src="/public/references/farm.png" alt="farm building icon" className="h-32"></img>

### Woodcamp

This category mainly produces **wood**. It is required in the late game when more and more
buildings start to require wood for efficiency. It provides low value at the start of the game.

<img src="/public/references/woodcamp.png" alt="Woodcamp building icon" className="h-32"></img>

### Watchtower

Currently has no effect in the game. In the future, we are planning to implement
it as part of a **fog of war** mechanic.

<img src="/public/references/watchtower.png" alt="Watchtower building icon" className="h-32"></img>
