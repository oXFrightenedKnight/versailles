## Requirements

Make sure you are logged into your account with Clerk. [How to create an account](/account/sign-up).

Make sure you have created at least 1 world. [How to create a new world](/fundamentals/creating-new-game)

## What are saves?

A save in Versailles is an object received from the server which contains important
game information like world data, metadata, game id, etc. All your saves are stored
in a database and are linked to your account.

## How to load a save?

### Step 1:

<Tabs>
  <Tab title="Via Top Menu">
    1. Press **"Saves"** link at the top of the page.

    <img
      src="/public/references/loading-saves-1.png"
      alt="Navigating save menu from home page image"
    ></img>

  </Tab>
  <Tab title="Via Quick Play Button">
    1. Press **Quick Play** rectangle at the bottom of the hero section of the home page.

    <img
      src="/public/references/loading-saves-1.png"
      alt="Navigating save menu from home page image"
    ></img>

    2. Once in Main Menu, click **"Load Game"**.

    <img
      src="/public/references/loading-saves-2.png"
      alt="Navigating save menu from home page image"
    ></img>

  </Tab>
</Tabs>

### Step 2:

Once the save menu has loaded, choose a save you would like to load and **click** on it.

<img
  src="/public/references/loading-saves-3.png"
  alt="Navigating 'new game' button from main menu page image"
  className=""
></img>

The game will load and automatically launch after couple seconds.
