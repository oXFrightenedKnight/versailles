## What is Building Consumption?

Building consumption is an important metric in Versailles that shows how efficiently the current building works
by comparing received and required amounts for each resource. Most buildings in the game depend on some sort of
resource in order to produce another resource. Buildings can only consume [Building Resources](/resources/building-resource).
Required resources and amounts depend on building level and category.
Players can see consumption data in the Building Consumption Component.

## Where to find the Building Consumption Component?

BCC can be found in the left-side panel in the [Building Menu](/buildings/building-menu).

## How to read the Building Consumption Component?

The component mainly consists of two sections:

1. Required resources
2. Total Building Efficiency

## Required Resources

This section displays all resources that this building needs to receive in order to function at 100%
Total Efficiency. Each required resource has a different weight, which means that each required resource has
a different percentage contribution to Total Efficiency. Each resource component includes:

1. Resource Icon. Indicates which resource needs to be received.
2. Amount bar. Compares received resource to total needed.
3. Percentage Impact. Shows what percentage this resource currently contributes to the Total Efficiency.

**Note:** buildings can only consume [building resources](/resources/building-resource).

## Total Building Efficiency (TBE)

Total efficiency is located at the bottom of the Building Consumption Component and shows total building
efficiency after totaling the percentage impact from each required resource. This number is used to directly
calculate the building's own resource output, army training, and population growth.
