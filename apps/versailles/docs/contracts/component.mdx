## What is a Contract Component?

Contract Component is a menu nested inside [Building Configuration](/buildings/building-menu)
to help player create and manage their contracts.

## How to create a new contract?

Follow these steps to create a new contract:

1. Choose a building you want to **export** from and a building you want to **receive** the exported resource.
2. Make sure you meet all [requirements](/contracts/contracts) for creating a new contract.
3. First, click on the building tile you want to send resource from. If this building is eligible,
   you will find a Contract Component inside [Building Menu](/buildings/building-menu).
4. Locate a **"Square Pen"** icon at the top of the component. Click on it to activate contract creation mode.
5. Click on **receiving** building tile.

## Reading a contract

All contracts are located inisde Contract Component and consist of the following features:

1. -/+ buttons. These buttons are used to adjust a contract's exported amount. **Warning:**
   changing contract amount will disable **"Auto-Adjust"** feature.
2. Amount label. Shows current export amount.
3. Auto-Adjust. Used to change contract type between "Fixed" and "Flexible".
4. Exported Resource. Displays current exported resource. Click to switch to another available resource.
